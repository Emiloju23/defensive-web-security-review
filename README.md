# Defensive Web Security Review

## Project Overview

This project documents a defensive security review of the locally hosted OWASP Juice Shop intentionally vulnerable web application.

## Obejective

The objective is to assess

-Authentication
-Input validation
-Session handling
-Access control
-Security headers
-OWASP-aligned security risks

## Scope

The review is restricted to the locally hosted application:

https://127.0.0.1:3000

No unauthorized live systems or third-part apllication were tested.

## Tools

-Ubuntu Linux
-OWASP Juice shop
-Firefox Developer Tools
-Curl
-Python
-Jupyter Notebook
-Git and GitHub

## Methodology

The assessment uses safe local, static, and manual techniques.
No destructive testing or unauthorized exploitation is perform.

## Limitation
The findings apply only to the local OWASP Juice shop deployment reviewed during this project.
